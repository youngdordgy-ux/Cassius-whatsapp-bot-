🔐 SECURITY

Create a ".env" file:

BOT_NAME=CASSIUS-TECH-BOT
PREFIX=.
OWNER_NUMBER=YOUR_NUMBER
TIMEZONE=Africa/Johannesburg
AI_API_KEY=YOUR_PRIVATE_KEY

Your ".gitignore" should contain:

node_modules/
.env
session/
auth_info/
*.log

🚨 Never publish your WhatsApp authentication files or API keys.

🚀 INSTALLATION

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/CASSIUS-TECH-BOT.git

2. Enter the folder

cd CASSIUS-TECH-BOT

3. Install dependencies

npm install

4. Start the bot

npm start
